What changed:

HOW TO USE
1. Extract this folder.
2. Keep index.html, style.css, script.js, your photo files, and the lyric video in the same folder (or update paths in index.html).
3. Open index.html in a browser, or use Live Server in Visual Studio Code.

The original photo files and AURORA lyric video were not included in the uploaded source files, so keep your existing media files alongside index.html. The video filename expected by the page is:
AURORA - Exist For Love (Lyric Video).mp4
